# CS 預測數據與選邊

此模組增加可讀數據，不更改訓練、主機率或正式資格。比分方向固定 A–B，機率以 fraction 保存；預期值不是最可能的整數比分。

## 計算入口

先完成 canonical forecast 驗證，再從 repo 根目錄執行：

```bash
python3 cs-analysis/scripts/summarize_forecast.py <run/forecast.json> \
  --output <run/cs-presentation.json>
```

腳本驗證原快照，保存 forecast ID、原 JSON 的 SHA-256 與衍生數據；不覆寫輸入、不中途調參、不取得價格。輸出沿用共用 create-only 行為，變更內容須另存版本。此檔與原快照一起歸檔，不能取代 canonical forecast 或 record。

`winner_pick` 為唯一較高勝率方；數值同率（共用浮點容差 1e-12）時為 null，保留 `winner_ties`，由已查證證據作定性取捨並在報告說明。`unmodeled` 不填衍生數字。兩者都不因取捨而改寫模型機率。

## 系列數據

令 `P(a,b)` 為完整系列比分分布，`N=a+b`：

| 指標 | 計算／意義 |
| --- | --- |
| A／B 勝率 | 加總 `a>b`／`b>a` 的所有比分機率 |
| 看好方代表比分 | 在該隊獲勝比分中取最大 `P(a,b)`；並列保留，機率使用無條件值 |
| 全分布比分眾數 | 所有比分中最大的 `P(a,b)`；與代表比分不同時另列 |
| 預期 A／B 拿圖 | `Σ a×P(a,b)`／`Σ b×P(a,b)` |
| 預期總圖／圖差 | `Σ (a+b)×P(a,b)`／`Σ (a−b)×P(a,b)` |
| 總圖分布 | 依 `a+b` 加總；大小圖由對應集合相加 |
| 圖 n 開打率 | `P(N≥n)`；不是圖 n 的勝率 |
| A 至少 k 圖 | `Σ P(a,b)`，條件 `a≥k`；B 同理 |
| 公允十進位賠率 | `1/p`；p=0 輸出 null，不填有限價格 |

一般無地圖優勢的 BO3：A −1.5 = P(2,0)，B −1.5 = P(0,2)，各與對方 +1.5 互補。BO5：A −1.5 = P(3,0)+P(3,1)，A −2.5 = P(3,0)，B 對稱處理。特殊賽制／地圖優勢先核對實際已打圖數與結算，不能直接把系列計分當成已打地圖數；本摘要腳本只適用一般 BO1／BO3／BO5。

BO3 至少一圖與 +1.5 等價；BO5 至少一圖與 +2.5 等價、至少兩圖與 +1.5 等價。BO1 不展開這些無意義市場。

## 單圖數據：正確條件化

有 `scenarios[].nodes` 時，摘要腳本先以 `series_tree` 重播，確認與各情境的比分分布相同。令情境權重為 w、到達圖 n 前路徑的機率為 m、該節點 A 勝率為 p：

`P(A 贏圖 n | 圖 n 開打) = Σ(w×m×p) / Σ(w×m)`

分母為 0 則圖 n 不會開打，條件勝率為 null；不能填 0%／50%。多情境的權重會因「已到達圖 n」改變，不能直接平均原始情境單圖率。腳本同時保存分情境與混合逐圖資料。

- 地圖名、選圖方與選邊從同次 event／veto 證據補入；scenario ID 必須對得上。不同情境圖 n 的名稱不同時，混合結果只叫「圖 n」，或逐情境展示。
- 多圖系列無條件樹時仍可由比分算開打率，單圖勝率標不可用，不能從系列勝率反算唯一一組逐圖率。BO1 只有一圖，單圖勝率直接等於系列勝率。
- 樹節點只是條件模型，是否真的納入地圖／名單仍依模型稽核判定；相同數字不代表已做出逐圖差異。
- Live 的單圖率須來自當前狀態模型；原賽前樹不適用。已完圖只列已知結果，未來圖才列預測；預期最終總圖數包含已完成圖，不冒稱剩餘圖數。

## 回合與選手數據：有模型再列

共用 CS v2 與此摘要腳本沒有回合／選手輸出。不得把 60% 單圖率任意映射成 13–9，或把歷史 ADR／Rating 換個標題當預測。使用者問這些時，先查可用逐回合／選手資料與適用模型，缺少才說未建模。

有額外可重現模型時，保存同一截止時間、來源、規則、參數版本與計算產物後，可追加：

| 預測 | 需要的輸出與資料 |
| --- | --- |
| 每圖回合比分／總回合／OT 機率 | 合法終局回合分布；當場回合制、加時、選邊與同圖同陣容資料；區間由分布分位數取得 |
| 手槍局／攻守回合率 | 對應樣本、對手校正、選邊與已實作估計方法；不能套固定 CT 優勢 |
| 選手擊殺／ADR／Rating | 實際先發、角色、地圖及預期回合數／曝光；明示場均或每圖、Rating 版本與模型適用性 |

回合模型若會改變單圖勝率，須自上游重建整個系列分布；若只是給定勝負的附屬預測，須保持原勝率並說明條件。新模型標實驗並獨立驗證，不能藉新增數據欄位宣稱命中率提升。
