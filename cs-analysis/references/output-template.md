# Counter-Strike 輸出模板

遵循 `../../shared/forecast/report-template.md` 的共用數值契約與 CS 專用呈現規則。完整性以使用者能否直接讀到結果及判斷依據驗收，不以字數、表格數或附件大小衡量。新數值先完成計算與驗證，再從同一 canonical JSON 呈現；模板不預填主推、機率或注碼。

## 模式選擇

| 請求 | 交付內容 |
| --- | --- |
| 單場分析；深入、詳細、完整分析 | full：聊天直接交付下列完整分析；深入分析須展開有證據的戰術對位、逐圖勝法與反證 |
| 單一機率、盤線或原因追問 | quick：先完整回答所問事件，再給必要組成、解讀及限制，不重貼整份報告 |
| veto、選邊、名單更新 | 更新：承接上一問題，核對新資訊，重算受影響結果並比較前後差異；使用者同時要求完整分析時套用 full |
| 即時比分／經濟／賽中追問 | live：已確認狀態、條件結果、變化與翻轉條件；不把只有 veto 的賽前重算稱作即時勝率 |
| 今天／整日賽事 | daily-summary：每場保留主要結果與判斷，最後合併總結表 |

## Full：正文內容

按「結論與賽事狀態 → 預測結果 → 逐圖與 veto → 陣容、近況及對位 → 價格決策 → 反證、缺口與來源 → 置底簡表」組織。可依使用者關注的市場提前相關內容；必要內容仍須在聊天中可見。

### 1. 結論與賽事狀態

- 具名雙方、台灣日期與開賽時間、賽事階段、BO 幾、LAN／Online、資料截止時間；已開打則明示當前能確認的狀態。
- 先回答較看好誰、系列賽長短傾向，以及使用者指定的盤線。雙方系列勝率、比分眾數及其機率都須能直接找到；接近均勢就說接近均勢。
- 模型狀態明示正式／實驗／基準／無法建模；模型信心度另標為證據品質評分，未知用 N/A。影響結論的重大缺口在此簡述，評分組成與完整模型紀錄放附件。

### 2. 預測結果

比分一律固定 A–B 方向並具名。系列賽衍生市場由同一比分主分布導出，不以信心度取代結果機率。下列等價關係適用一般無地圖優勢、無特殊結算的完整系列；特殊賽制先核對規則。

| 賽制 | 正文必列結果 |
| --- | --- |
| BO1 | 雙方單圖勝率與公允賠率；多圖總數、至少一圖與地圖讓分標為 N/A（BO1），不展開無意義市場 |
| BO3 | 雙方獨贏；2–0、2–1、1–2、0–2 全部分布；雙方各自至少一圖（+1.5）；兩隊皆拿圖／>2.5；恰好 2、3 圖的機率 |
| BO5 | 雙方獨贏；3–0、3–1、3–2、2–3、1–3、0–3 全部分布；雙方各自至少一圖（+2.5）及至少兩圖（+1.5）；>3.5、>4.5；恰好 3、4、5 圖的機率 |

- 獨贏雙邊及關鍵總圖數列模型公允十進位賠率；其餘已問或已取得價格的市場補齊相關機率與公允價。比分可用兩隊並列短清單，無須把每個比分展成大表。
- 比較讓分／大小圖盤時列同一盤線的雙邊機率。BO3 的 -1.5 為該隊 2–0；BO5 的 -1.5 為該隊 3–0 或 3–1，-2.5 為該隊 3–0；與對手相反受讓互補，不混用 BO3／BO5 的至少取圖門檻。
- 解讀比分分布：眾數只是最高的單一結果。若最可能勝方與比分眾數方向不同，說明勝方取各獲勝比分加總；並列峰值如實列出。
- >3.5 代表至少打到第 4 圖，並非一定打滿 5 圖；>4.5 才是打滿 5 圖。單隊至少一圖與兩隊都至少一圖分開標示。
- 公允價為 `1/p`，不等於可下注價格門檻；機率為 0 時不列有限公允價。無法建模時列缺口與可支持的定性判斷，不能填 50% 或捏造機率區間；若列敏感度範圍，交代情境與計算來源，不冒稱統計信賴區間。

### 3. 逐圖與 veto

先區分官方公布、可靠比賽頁、使用者提供待核實、尚未公布的推測。確認當場地圖池；不能從五張圖的順序自行補出誰 pick、誰 ban 或先選哪邊。未知欄位直接標記。

正文用逐圖表呈現，欄位可依資料調整：

| 圖序／地圖 | 選圖方／選邊狀態 | A／B 單圖勝率 | 樣本與可比性 | 判斷與信心 |
| --- | --- | --- | --- | --- |
| 依當次 veto 或具名推測情境填入 | 已確認事實；未知明示 | 同一模型輸出，兩邊合計 100% | 兩隊各自勝敗／樣本數、期間、同陣容與對手層級 | 該圖優劣理由、證據品質或缺口 |

- BO1 列目標單圖、BO3 列三圖、BO5 列五圖；未定 veto 用已建模情境或候選圖表達，不能假裝圖序確定。已 ban 地圖另用短句說明其影響。
- 每張圖回答哪一方較有利、憑什麼、對手如何取勝。結合可取得的 T／CT、AWP／entry／anchor 對位、首殺轉化或收尾證據；避免只寫「熟圖」「火力強」「地圖池深」。資料不足可逐圖指出，不能以整體排名複製五張相同理由。
- 區分歷史地圖勝率與本場模型勝率；說明樣本時間、陣容異動、對手品質及收縮的影響。新圖／改版小樣本不能沿用舊圖印象填數。
- 對尚未必然開打的地圖，說清單圖率是給定該圖開打時的估計；到達圖 4／5 的機率屬於系列分布，兩者不能混用。
- BO5 說明前 3 圖哪裡可能阻止橫掃，以及進入第 4／5 圖後誰有利。後兩圖的優勢不直接證明一定能打到它們。

### 4. 陣容、近期表現與對位

依 `domain-analysis.md` 查核，正文留下足以支持本場判斷的資料：

- **當場名單與角色：** 兩隊五人、IGL／AWP 等關鍵角色及有影響的教練、替補或近期異動。確認與推估分開，不確定的角色不填成事實。
- **近期可比表現：** 兩隊各有具名對手／日期／賽事或可追溯的統計期間、樣本數，說明勝敗含金量、同陣容程度與 LAN／Online 可比性。H2H 核對名單與地圖，不把過期交手當成當前實力。
- **本場勝負機制：** 把近期證據連到本場地圖或角色，再交代對手的反制。雙方勝法都須被解釋；使用者要求深入分析時，展開關鍵地圖的攻守、開局經濟與收尾路徑，有資料才量化。
- **模型確實用到什麼：** 區分已進入模型的輸入、僅作定性判斷的證據、尚缺的資料。若模型只使用有限樣本或比分基準，清楚說明，不能把較豐富的戰術敘述包裝成已量化的預測。

每個關鍵事實附就近來源；推論寫明是推論。查核結果依可比性組織，不逐場抄比分充篇幅；缺資料時交代查到什麼、缺什麼及對判斷的影響。

### 5. 價格與決策

先鎖模型機率，再接入盤口。依已取得玩法呈現「選項／盤線、模型機率與公允價、實際十進位賠率、EV、決策」，來源及價格時間放表前後；只取得獨贏就明示其他市場尚無價格。

- 有價且結算規則一致才算 `EV = p × 十進位賠率 − 1`；來源不足不猜價、不估 EV。公允價與市場價分開。
- 回答使用者指定的總圖數或讓分，不只給獨贏建議；若沒有價格，仍交付該事件機率、公允價及資料限制。
- 正式資格與價格優勢共同決定建議。未校準基準／實驗、缺可追溯價格時維持 0u；正的算術 EV 不等於已驗證的投注優勢。狀態集中說明，不在每段重複。

### 6. 反證、缺口與來源

交代最可能推翻判斷的具體條件，例如 veto 與預期不同、關鍵角色臨時異動、某圖的收尾弱點被針對。依證據選出影響大的因素，不用泛稱「電競有變數」代替分析。

已計算的替代 veto／選邊情境可列勝率、目標盤線的變化及原因；尚未建模的機制只寫定性風險。所有關鍵缺口均指出影響哪張圖或哪個結論。來源、資料截止時間、完整報告與快照連結置於總結表前。

## Quick：單一機率或盤口追問

先用一段或小表回答：**所問事件與機率 → 組成及含義 → 公允價／有價才列 EV → 當次估計的主要限制。** 沿用既有已驗證快照時註明版本／截止狀態；沒有新事實不為追問重造機率。報告連結只是補充，單一結果不強制附五欄總結表。

例如使用者在 BO5 後問「>3.5 的機率多高」：直接給 >3.5，補上恰好 4 圖與 5 圖的機率、公允價，解釋主要橫掃風險及是否已納入 veto。不能只回答獨贏；也不能只給百分比而漏掉這是賽前估計或即時條件估計。

無地圖優勢的標準 BO5 中：

`P(>3.5) = P(總圖數=4) + P(總圖數=5) = 1 − P(3–0) − P(0–3)`

`P(>4.5) = P(3–2) + P(2–3)`

用完整精度導出與核對，再四捨五入。使用者追問「為什麼」時展開支持該事件的逐圖與反證，不套入整場固定摘要。

## Veto／陣容更新：延續原問題

1. **先交代收到的狀態。** 重述圖序或名單變動及來源，補查官方／比賽頁；無法獨立確認時標「使用者提供、待核實」。若只有地圖名稱，依對話作為圖序的工作假設並明示，不能補出選圖權與選邊。
2. **對照前一快照。** 指出哪些假設被確認、哪些改變、哪些仍未知。沒有前一版可比資料就說是首次按此 veto 估計，不編造升降。
3. **逐圖更新後重算。** 展示確定或假設的完整圖序、各圖 A／B 勝率及關鍵理由；名單更新則指出影響的圖與角色。若已開打卻沒有比分，標為按 veto 重建的賽前條件情境，不稱作 live。
4. **先回答原本關注的市場。** 有可比快照時列「項目、前次、本次、變化（百分點）、原因」。例如前問 >3.5，就先列 >3.5，再補恰好 4／5 圖、兩隊橫掃機率及獨贏；完整新比分分布仍須保存。要求 full 才重列全部正文。
5. **解釋數字變或不變。** 檢查新資訊是否實際改變模型輸入；若不同地圖被基準映射成相同參數，披露模型分辨能力不足。不能為了看起來有更新而手調勝率，也不能未重算就沿用舊數字。僅圖 4／5 的假設改變、而前三圖條件分布保持相同時，>3.5 可以不變。

## Live：即時條件分析

已確認局勢與時間 → 使用者所問事件的最新條件機率 → 相對前一快照的變化 → 影響最大的攻守／經濟依據與失效條件 → 價格狀態。以短段交付即時答案；使用者要求深入時再展開，不以「極度緊湊」省略關鍵狀態或結果。

- 標出系列大比分、當前圖、已結算回合比分、雙方 T／CT、換邊與可用經濟資訊。未知明示；分開列比分狀態時間與價格時間。
- 依 `domain-analysis.md` 第 7 節採用能接受當前狀態的模型，只保留可達終局。多市場更新列當前地圖勝率、系列勝率、可達比分及受影響總圖數；單一市場追問聚焦該事件與其必要組成。
- 已確定的事件標「已確定」並說明仍以結算規則為準；不把它當成新的預測優勢。缺 live 模型或狀態時，只交付可確認的局勢及條件情境，不把賽前數字改名為即時勝率。
- 需要總結表時，比賽欄標 `Live`、圖序與比分；核心預測放當次問題對應的條件結果，建議來自同步價格及已驗證決策。

## Daily-summary

先依台灣時間盤點完整目標集合，再逐場列雙方勝率、全部適用比分、至少一圖、關鍵總圖數、veto／陣容狀態、關鍵依據與市場決策。場次多時壓縮理由與名單，仍保留每場結果覆蓋；無法建模的場次保留原因。逐圖研究明細存逐場完整報告，使用者要求逐場深入時展開 full。全日最後合併一張五欄總結表。

## 完整報告、渲染與交付檢查

完整報告沿用 full 正文，研究附件保存逐場原始資料、來源內容與時間、模型輸入、情境權重、五項信心組成及執行紀錄。通用 renderer 的 `chat` 模式只產摘要，不能直接作為 CS full 交付；發布呈現層須從相同已驗證 JSON 與證據補齊本模板內容，不另估數字。

交付前按當次模式核對：

- **能否直接回答：** 不開附件也能找到所問機率與解讀；full 可找到雙方勝法、逐圖判斷、完整比分及適用衍生市場，缺項有具體原因。
- **數值一致：** 比分總和 100%、獨贏等於獲勝比分加總、總圖數與橫掃／取圖關係一致；表格、文字與附件使用同一快照及 A–B 方向。
- **證據支撐：** 近期樣本、當場名單、veto 與未知選邊可辨識；歷史地圖勝率、模型單圖率、到達後續地圖的機率與證據信心沒有混用。
- **更新可追溯：** 新資訊是否進入模型、何者改變／不變及原因均有交代；沒有把重排文字、賽後重建或基準模型宣稱為新的即時預測。
- **交付版本：** 依 `../../shared/report-storage.md` 保存及歸檔。純呈現修改沿用 forecast ID、另存報告版本；新預測新增快照，不覆寫歷史預測。

## 置底簡表

正文允許逐圖、比分、價格及更新比較表；**只有總結表限於末尾一次**。full／daily-summary 保留五欄；單一 quick 可略過，聚焦更新若使用此表則以所問市場作核心預測。連結、來源與附註均放在總結表前。

| 比賽 | 核心預測 | 模型信心度 | 建議 | 核心風險 |
| --- | --- | --- | --- | --- |
| 台灣日期／時間、A vs B、BO | 勝方與勝率；比分眾數與機率。聚焦更新填目標市場及機率 | 證據品質評分；未知用 N/A 與原因 | 當次已驗證決策或明確觀察條件 | 主要翻轉條件 |

## 賽後模式

賽果與原快照 → 逐圖及系列偏差 → 可重複錯誤機制 → 基準／挑戰版比較 → 實驗裁決及回退條件。命中、機率品質與原始資料限制分開解釋；沒有產生新預測時不附賽前簡表。
