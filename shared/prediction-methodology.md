# 預測判斷與證據使用

新建或更新機率時使用；計算與保存依 [forecast/contract.md](forecast/contract.md)，呈現沿用現有模板。目標是提高未來同類賽事的勝方命中與機率品質，避免用敘事強度、更多搜尋或更保守的措辭代替改善。以下是判斷準則，不要求逐項對外列章節，也不要求展示內部推理過程。

## 先確認模型能回答什麼

先固定賽事 ID、參賽者方向、資訊截止、賽制與結算範圍，再找適用的既有模型及其輸入契約。production 必須有同領域、同預測時點的適用證據；baseline 可提供參考機率，不能因能重播就升為正式模型。LoL 的分析者情境與 MLB 的分階段 baseline 沿用專用路徑，不把共用比分模型當成唯一入口。

檢查實際讀取的輸入、已擬合參數與 missing_data。JSON 多放傷兵、draft、天氣或回合比分，不表示計算程式會使用它。模型不支援的項目保留為未量化風險或隔離候選；不要聲稱其效果已包含在勝率內。缺少進階特徵時先完成可得領域研究，再依現有降級規則交付基準，不能用工具成功替代分析完成。

開賽後的模型必須能以已完成局／回合與剩餘賽程為條件，排除不可能終局。共用 `models.py predict` 目前沒有回合經濟或 live 狀態輸入，不能只換 snapshot 名稱就稱動態重估；找不到適用入口時保存即時事實、可計算的條件結果與未建模缺口，不把賽前分布冒充 live。賽後重建與正式賽前樣本分開。

## 研究以會改變判斷的缺口為中心

- 先查事件身分、最新有效陣容／角色、賽制與版本，再補最可能改變方向或主分布的領域證據。關鍵來源失敗時依 source-priority 換來源或定位原始頁；可並行查獨立資訊，不為湊來源數反覆抓相同內容。
- 核心事實保存來源、內容定位、事件／局次、內容可知時間及查核時間。摘要只作索引；轉載同一公告不算兩個獨立來源。今天重新開啟的舊頁不算新證據，較晚擷取也不使較舊名單優先。
- 對衝突資料比較當場適用性、原始性及發布時點；不能平均互斥事實、按網站票數裁決，或用記憶補齊。仍未解決則保存衝突及受影響結論；若連對戰／結算都不明，該部分不能數值化。
- 近期內容須保留對手、陣容、版本、主客／地圖／角色與樣本數；納入可比敗局與反例。同一比賽不要因近7／14／30天重疊、H2H與近期戰績重疊或多個相關指標而重複加分。不能用終場勝負倒推前期內容。
- 已回答關鍵問題且新來源只重複內容時停止擴搜。剩餘缺口記錄查過的路徑、影響及重新查核條件；保留可交付部分，不以第一個404中止，也不無限搜尋到「完全確定」。

## 讓領域證據真正連到預測

對影響結論的論點，留下足以核對的簡短依據：可定位的觀察 → 本場可重複機制與對手應對 → 使用位置 → 推翻條件。它可放入現有分析內容或 run 附件，不新增固定輸出表格。

使用位置要分清：

- **模型已使用**：指出實際輸入欄位／特徵及版本；核對方向、單位、樣本與處理缺失的方式。若基準已吸收同一訊號，不再手工加一次。
- **分析者估計**：只走該領域已存在且可重播的實驗入口，明示主觀權重／條件率的依據、反證與合理範圍。來源能支持機制，不代表能唯一決定數值。
- **未量化風險**：說明未映射原因、可能影響及可觀察翻轉條件；重大風險若與基準相反，結論明示適用限制。不能暗示風險已調整機率，也不能為消除差異而倒推參數。

小樣本收縮、時間衰減、共同狀態及集成權重依模型版本或訓練決定。歷史手動加減百分點、固定因子比例、爆冷／和局下限都不是校準證據。沒有可重播映射時可建立 candidate；不能把新增敘事當成新因子已上線。

## 反證與敏感度

初步判斷形成後，檢查最有力的相反證據：對手能如何切斷主要勝法、支持資料是否只來自弱對手或舊陣容、某項假設是否承擔大部分優勢。先查反證是否真實且適用，再決定是否更新；不要求湊固定數量的反模型，也不因想得到清楚主推而放大差距。

未定先發、veto／draft、工作量或關鍵參數可能翻轉結論時，用該入口支援的替代輸入重算並保存結果。情境需有來源、可區分的狀態與合計為1的權重；不能把「A贏／B贏」當成機制，或無個別依據地照搬其他場次參數。相同／鏡像數字本身不證明錯誤，有各場依據即可保留。未知權重不自動設50/50；缺少可用入口時明示未量化，不自行補數字。

壓力測試與主要預測分開保存，不挑測試中有利端點作正式機率。LoL 沿用 `analyst_forecast.py audit` 或 `audit_baseline_sensitivity.py` 的適用診斷；其他領域先核對工具支援，不照搬 LoL 的固定擾動幅度。敏感度範圍不是信賴區間，沒有翻轉不代表已校準。事實更正後新增完整快照，重算相依數值；參數維持不變也需說明原機制仍成立的依據。

## 鎖定、交付與品質界限

- 所有相依機率從同一主分布導出；勝方、比分眾數、至少一局及總局數不分開猜。領先條件、互斥結果、走盤與隊伍順序先核對，再驗證總和及重播。
- 信心度沿用五項權重：完整度25%、新鮮度20%、先發確定度25%、制度相關性20%、模型穩定性10%。依當場證據評分，沿用該版本的 N/A／評分規則；它不等於勝率，也不由市場價格、模型名氣或輸出長度決定。
- 在同一份已保存資料上生成既有報告。來源支持論點、論點與實際輸入相符、計算與正文一致，三者均核對後才算完成；純排版沿用原預測 ID 及數字。
- 機率鎖定後才查價格與計算結算 EV。使用者已提供價格時先隔離為市場資料，不稱自己從未看過價格；保存參數來源，不讓價格或預想投注方向決定勝率。注碼與個人偏好沿用既有規則。
- 沒有當時資料就累積前瞻樣本，不補造歷史快照。命中、比分與 Brier／log loss 分別衡量，不能以一項改善推論其他項也改善。賽後流程見 [postmortem-improvement.md](postmortem-improvement.md)；skill／提示變更的配對驗收見 [evals/prediction-quality.md](evals/prediction-quality.md)。
