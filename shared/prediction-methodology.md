# 預測方法入口

新預測讀 `forecast/contract.md`。共用實作在 `forecast/core.py`、`models.py`、`evaluation.py`；領域內容依各 skill。

1. 賽事、資訊截止與預測版本先鎖定；更新新增快照。
2. 時間窗不重複計數；小樣本向基準收縮。可選因子遵守登錄狀態，模型參數由訓練資料或標明未校準的版本契約決定。
3. 情境權重及情境內主分布可重播；沒有證據不造情境。
4. 所有相依結果由同一主分布推導。勝方與比分眾數分開取最大值，保留可能的方向差異。
5. 模型信心度五項權重仍為完整度25%、新鮮度20%、先發確定度25%、制度相關性20%、模型穩定性10%。它是證據品質評分，不是命中機率；未知則 N/A 與原因。
6. 市場只能在機率鎖定後比較價格與結算期望值，不能用價格改模型。
7. 預測成效以勝方命中優先、比分次之；另報 Brier、log loss、分布誤差、覆蓋率與可用率。使用配對時間序列驗證；不能以校準改善自動宣稱命中提升。
8. 詳細賽後因子治理與升版按 `postmortem-improvement.md`。沒有原始快照或當時資訊集時不重建假基準。
