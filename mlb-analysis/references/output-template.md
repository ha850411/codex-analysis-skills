# MLB 輸出模板

完整分析使用此模板。若使用者要求簡版，可保留核心欄位並壓縮文字。

先標示模型層級：`validated-production`、`public-data-baseline` 或 `unmodeled`。沒有生產模型時先執行公開資料 baseline；只有 baseline 也失敗時才交付 `degraded` 本地報告並填 `N/A`。自動排程不得把全 N/A 報告發布成正常每日預測。

## daily-summary 壓縮與精簡規則

整日多場報告使用下列精簡結構，解決 `.md` 與 Notion 報告內容過於冗長繁雜的問題：

1. **全日總覽**：模型層級、數值覆蓋率、最高／最低方向性勝率、觀測 Tier 分布、逐場模型信心度範圍、下注資格與資料截止。
2. **🔥 每日精選 Top 3 最穩推薦 (Solid Picks)**：
   - 依「模型信心度 (Model Confidence)」高低與進場門檻，精選最多 3 場最穩比賽（若無高信心度或符合門檻場次，可顯示少於 3 場或標註「今日無符合門檻之強推場次」）。
   - 每場包含：對戰組合、勝率與公允價、推薦標的/門檻價格、核心推薦理由、場次專屬風險。
3. **今日 MLB 賽程盤點與模型比較 (依信心度降序排序)**：
   - **所有場次一律依照「模型信心度 (Model Confidence)」由高至低（降序）排序**，不需要按比賽開賽時間排序。
   - 一張簡潔表格整合全場賽程與模型預測，欄位包含：信心度、比賽組合、台灣時間、期望得分與 80% 區間、全場勝率(含公允價)、前五局三路(標明隊名)、大小分預測、觀測推薦與門檻價格、場次專屬實務風險。
4. **重點觀察名單 (最多 3 場)**：精簡說明先發關鍵、打線/牛棚/環境缺口與等待進場門檻。避免為每一場複製完整單場細節。
5. **簡表總結**：全文最後輸出唯一的簡表總結，同樣嚴格遵循**依信心度由高至低排序**。

### 欄位格式規範（全場比較表與簡表總結必須遵循）

- **小數點精確度規範**：所有數據與數值（勝率%、公允賠率、期望得分、門檻賠率等）一律計算並四捨五入保留至**小數點第二位** (2 decimal places)。
- **排序原則**：所有列表必須按 `模型信心度` 由高至低降序排序 (例: 65.00% > 61.50% > 55.00%)，不得依時間排序。
- **全場勝率（含方向性與公允價）**：必須完整標示雙方勝率、勝方傾向與公允賠率。格式：`[勝方傾向] [勝隊] [勝率]% (公允 [賠率]) | [被看淡隊] [勝率]%` (例：`主勝傾向：水手 54.92% (公允 1.82) | 紅人 45.08%`)。
- **前五局三路**：必須明確標示客隊、平手與主隊。格式：`[客隊簡稱] [客勝]% / 平手 [平]% / [主隊簡稱] [主勝]%` (例：`紅人 36.58% / 平 16.95% / 水手 46.47%`)。
- **大小分預測**：必須包含模型預估總分、80%區間與基準盤口傾向（Over/Under勝率）。格式：`[預估得分]分 (80%區間 [p10]–[p90]) | [大/小分傾向] (盤口 [線]分, [勝率]%)` (例：`8.40 分 (3.00–14.00) | 小分傾向 (< 8.50 分, 52.40%)`)。
- **推薦 / 觀測與進場門檻**：`public-data-baseline` 雖然注碼固定 0u，但必須給出方向標的、公允價格、進場門檻與觀測 Tier。格式：`[觀測 Tier] [標的] (公允 [賠率], 進場門檻 >= [門檻賠率]) | 0u` (例：`[Tier 1 觀測首選] 水手 ML (公允 1.82, 門檻 >= 1.85) | 0u`)。
- **核心風險**：必須列出**場次專屬實務風險** (如：`雙重賽 G2 晚場投手與打線異動`、`BOS 先發 TBD`、`Coors Field 高海拔極端總分波動`、`雙方接近 50/50 波動高`)，嚴禁逐場複製相同的全域樣板文。
