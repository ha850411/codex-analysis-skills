# LoL 領域分析：從比賽內容形成判斷

本使用者的近期證據、數字呈現與總資金百分比配置，優先依 `user-decision-preferences.md`；下文模型投注資格不等同主觀資金配置。

適用 full／daily-summary；quick 沿用已核實快照，不重做全部查核。賽程、先發分類與來源優先序只維護在 `source-priority.md`；數字、狀態與快照依 `../../shared/forecast/contract.md`；排版依 `output-template.md`。legacy v7 的集成、因子、上限與日報驗證只在使用該入口時讀 `forecast-evidence-gates.md`，不再混進本文件。

## 研究到什麼程度才交付

對雙方同賽事最近兩個系列，以及近30天可比直接交手，先查實際五人、版本、每局結果、選邊及局內內容。不足兩系列列全部；不可跳過較新的敗局。結果與全季資料可作模型背景，不能取代這批最近內容。

深入報告至少應具備：雙方各一個有場次／局數定位的實戰機制、該機制在本場如何遇到對手的應對，以及會推翻判斷的可觀察事件。不是湊固定數量的優缺點；若一邊沒有可驗證的勝法，明示查核缺口而不替它編造兩條。公平比較不要求兩隊評價相同。

資料缺口先作針對性補查，保存來源內容、查核時間、結果及替代路徑：

- 官方前端空白：讀同頁內嵌事件資料／可用官方 API，再交叉獨立事件頁；用事件時間戳判斷，不依「Today／Tomorrow」快取。
- Games of Legends 點擊形成錯誤相對 URL：核對並開啟正確 `/game/stats/<id>/page-game/` 或 `/page-summary/`，不要把錯誤路徑當資料不存在。
- 文字缺英雄：檢查 HTML 的圖片 alt／title、隊伍位置、逐局頁或比分截圖；與另一份記錄交叉。角色錯位時隔離該欄位，繼續使用已核對的其他資料。
- 局內內容優先讀結構化 BP、經濟與物件時間線、逐局統計及可追溯文字回顧。文字回顧中的操作判讀標示為來源觀點，不能當成親自觀看的結論。
- 不啟動 VOD／精華搜尋、播放、影格或逐字稿分析；沒有影片證據不影響分析完成度。真正缺少的 BP／時間線欄位各自記錄，不以「未看 VOD」統稱資料不足。

成功取得足以判別機制的材料就停止重複搜尋；相關替代路徑仍失敗時，交付有明確缺口的分析，不無限重試。網站限制不要求使用者重新提供已可自行查到的內容。

## 五人與可比性

按 Top／Jungle／Mid／ADC／Support 列出實際五人，保留 `confirmed`／`established`／`projected`。固定五人連續兩系列且現役頁一致、沒有更新輪替證據時，不再等待例行當場公告。

近期換人、舊 H2H 或跨 Split 輸入依 `roster-baseline-audit.md`：把可比與不可比的系列標明，不把舊選手的英雄池、指揮或對線資料移給新人。陣容不同不代表全部歷史無效，須解釋哪些訊號仍可轉移、哪些不能。

## 對位分析：只展開會左右勝負的位置

每項重要判斷用「觀察 → 機制 → 對手應對 → 本場推論 → 反證」串起來，附具體系列／局數、時間窗、樣本數及來源。區分實測事實、分析推論與尚待確認假設。

- **上路與邊線**：弱邊是否需要打野保護、反選能否換成線權、TP與邊線壓力是否實際影響物件。單次單殺不等於持續對位優勢。
- **中野**：首輪刷野與回城、推線窗口、入侵時隊友能否先到、先手控制與傷害能否接上。終場 KDA 不能反推出15分鐘經濟差或前期壓制。
- **下路與輔助**：線權來源、換線／回城時機、輔助遊走代價、ADC輸出空間及保排。高 DPM 要連同英雄、時長及經濟占比解釋。
- **物件與收尾**：首龍／首塔／先鋒、巴龍前視野與兵線、領先轉物件、落後交換資源。總控龍數不能當控龍率；獲勝不能直接當成穩定控制。偷巴龍、單次團戰逆轉需區分可重複準備與偶發失誤。

不要為了五個位置齊全而各寫一句空話。主結論應指出真正的主戰場、誰較容易執行、另一隊如何破局。

## 版本、BP、選邊及 Fearless

版本逐聯賽／階段核實；近期賽後頁可證明該場版本，不能自動證明今天版本。無當場版本時，保留最近已知版本及適用限制，分析已知組合的功能，不列無來源的「版本必搶榜」。

取得 BP 時，重點是組合功能與資源分配：一搶／搖擺位、ban 壓力、線權、前排、開戰、保排、持續輸出、傷害類型與裝備時間點。明確指出哪個 ban 或選擇會切斷主要勝法；不能僅列英雄名稱或選取率。

Fearless 按系列重置。前一系列用過的英雄在本系列仍可能可選，不能視為已耗盡；同一系列後段則需檢查替代方案。未見第四、五套實戰解法，不應宣稱 BO5 英雄池深度已被證實。使用情境估計時，未知 G4/G5 機率是分析者假設，不能當成實測能力。

首局選邊未知時不猜藍紅方。可分析「若取得一搶」「若需先暴露中路」的條件，只有可辯護的權重才量化。不要把選邊未知單獨當成停止所有分析的理由。

## 系列走向與反證

- 最近1–2週、同賽事與可比陣容內容優先；品牌與全季排名只作背景。模型若與這些內容相反，必須解釋差異是已建模證據、未建模因素、樣本選擇或模型能力不足。
- 近30天直接再戰，逐局檢查前次勝法是否仍可用、對方是否已展示反制。舊勝負、單次重擊或對手失誤不能自動外推。
- BO3 檢查首局及連勝收束；BO5 檢查落敗後是否真的改變 BP／資源分配、G3以後的組合完整性。剛打滿不能一律扣疲勞，較久休息也不能一律加分。
- 提出雙方可執行的系列勝法，再判斷主分布的橫掃、讓一局、決勝局形狀是否合理。比分眾數只領先第二名極小差距時如實說明，不用「主推3–1」營造確定感。
- 市場取價後如出現分歧，查是否漏掉名單、版本、選邊或結算資訊；找到新事實才重建快照。價格本身不是改勝率的理由。

## 從領域判斷到數字

依 `forecast-fallback.md` 選路。適用正式模型可作主預測；可追溯挑戰版保持實驗狀態；具體領域證據足夠但沒有已擬合映射時，可用 `analyst-scenarios.md` 的分析者估計。只有比分時保留基準數字及其有限辨識力。

每項核心因子說明是「模型實際使用」「分析者參數依據」或「未量化風險」。可重播不是已校準；未校準也不是禁止思考。不能先選想要的勝方，再倒推情境權重。

投注依 `../../shared/markets/collection-contract.md` 及所用模型資格；有資格的模型再讀 `recommendation-gates.md`。0u 報告仍須回答：哪一方較有可重複勝法、最值得看的第一個訊號、出現何種反證會改判。不要承諾只靠價格就能解除模型資格限制。
