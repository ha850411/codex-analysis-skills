# 資料不完整時的預測交付

使用者要的是可判斷對錯的預測。預測是否可計算、證據品質是否高、是否值得下注，是三個分開的決策。沒有完整 BP、VOD、當場先發公告、首局選邊、確定版本或價格，不得單獨作為放棄隊伍層級預測的理由。

## 選擇路徑

- 已有適用且可追溯的模型：使用其正式或實驗版本，保留適用範圍與限制。
- 完整領域證據不足：使用共用 v2 `baseline`，明示「未校準基準」。以查得的近期正式系列結果建模，未知 BP／輪替效應不加入參數，放入 missing_data 及信心度理由。不要為填滿 legacy v7 而發明三個模型或情境權重。
- 只有賽事身分、雙方、賽制仍無法確認，或合理補查後沒有可用的賽前結果／適用既有模型，才使用 `unmodeled`。若模型只是讓雙方都套無差別預設先驗，不能冒充有資訊的預測。保存逐隊查找結果、實際計算失敗原因及已嘗試的替代來源，不得把未執行建模寫成模型不能執行。

缺少新公告不等於已證明有換人；存在實際輪替時保留具名候選及來源。不能估計其效果時，仍可使用隊伍層級基準，明示未建模輪替效應，不自行配出看似精確的情境權重。

已知實際輪替或歷史陣容不同時，依 `roster-baseline-audit.md` 保存受影響系列並執行逐系列敏感度；擴寫報告也沿用其中的證據差異稽核，不能把基準輸出重新包裝成已量化的戰術優勢。

## 共用 v2 的執行

先完成賽程查核。收集雙方近期正式系列及可取得的同賽事對手資料；優先最近兩個系列，樣本不足或交手稀少時擴充同階段結果，再按可比性擴充較早資料。保留全部納入／排除理由，不只挑支持預想勝方的比賽。

依 `../../shared/forecast/contract.md` 建立 history 與 event，用 `../../shared/forecast/cli.py` 的 `train --variant baseline`、`predict` 產生完整比分主分布，再 `validate`、`record`、`render`。具體參數查各子命令 `--help`。history 的來源、結果可用時間與時間精度必須可追溯；不得編造發布時間來通過驗證。已知只有比賽日期時，須揭露日期精度與保守時間界限，不能冒充精確完賽時間。

訓練資料與輸出保存於同一新 run 目錄。補存逐場評分理由、名單查核與版本缺口。共用 v2 不要求 legacy v7 的三模型集成、因子資格或 daily validator；整日仍須通過 schedule v2 完整性驗證，且逐場 canonical forecast 均須驗證。模型沒有實作的戰術特徵只能作解釋與風險，不得手改模型勝率或比分。

先鎖定預測再收集市場。baseline／experiment 可交付勝率與公允賠率，但未通過正式推薦資格時維持 0u，不以市場價格補出模型勝率。

## 數字信心度

每場評估共用五項：`data_completeness` 25%、`freshness` 20%、`lineup_certainty` 25%、`regime_relevance` 20%、`model_stability` 10%；各為 0–100，總分按 core.py 加權四捨五入。它是分析者對證據品質的評分，不是經實證校準的命中率。

逐項寫理由，以下為評分錨點，不是預填分數：

- 完整度：結果、名單、局內資料均可核對時高；只有系列比分及部分名單時中低；基礎結果仍有衝突時低。
- 新鮮度：依資料本身距比賽多久及更新覆蓋評估；今天重新開啟舊頁不等於內容新鮮。
- 先發確定度：已核實當場或 established 五人時高；有最近實戰五人但公告查核不足時中；確有未解輪替時低。不能因未收到臨場公告就一律低分。
- 制度相關性：同階段、可比陣容與足夠系列時高；少量或跨版本、跨階段資料時中低；主要靠舊先驗時低。
- 模型穩定性：有適用的樣本外證據及敏感度結果才可高分；未校準基準且尚無穩定性實驗時使用低分並揭露。不能因模型可重跑就稱穩定，也不能因此整欄填 N/A。

低／中／高區間可分別以 0–39／40–69／70–100 描述，每個實際分數都要附當次依據。缺失項目依已知缺口評低分，不把其他項目的高分複製過來。共用 v2 使用其原生五項加權，不能手改總分以套 legacy v7 非補償式上限；採 legacy v7 時才依該路徑計分及驗證。數字信心度與模型版本同時顯示，避免將基準品質分誤稱投注把握。

## 發布前檢查

每場回答「選誰、勝率多少、最可能比分及其機率、信心度多少、為何、何種條件會翻轉」。全部機率由同一主分布導出；不能為迎合定性傾向另選勝方。勝率接近或比分並列時照實揭露，不捏造唯一峰值。只有上述真正 unmodeled 例外才可缺數字。

回看先前失敗情境：已確認 BO5 對戰、雙方近期系列比分可得，但 BP 部分不可讀、ADC 曾輪替、缺首局選邊。正確行為是執行隊伍基準並給出有理由的數字信心度，再說明輪替及 BP 風險；不是直接交付「定性偏某隊、N/A、觀察」。
