# 勝法能否轉移到本場

適用近30天可比再戰、兩隊實戰空窗不同，或以「多套功能組合可重複」支撐情境。這是既有 BP／對手可轉移性研究的稽核，不新增自動加減分；參數修正仍依 `analyst-scenarios.md` 與共用改善契約。

## 從證據到權重

對真正影響方向的機制，在現有研究附件或 `mechanism-transfer-audit.json` 保存下列對照即可，不另增聊天章節：

| 項目 | 要回答的問題 |
| --- | --- |
| 原始定位 | 哪個系列／局數／五人／版本支持？有哪些同條件敗局？ |
| 成立條件 | 需要何種線權、先手、承傷、跟進或輸出空間？哪些已實測，哪些僅從陣容推論？ |
| 對手阻斷 | 本對手是否曾以反進場、上野威脅、控制或兵線拆開這條鏈？熱門方有何已展示的回答？ |
| 可用解法 | 不同組合共享哪些必要英雄／功能？同系列 Fearless 下能否先後合法使用？ |
| 權重與條件率 | 證據支持的是機制可行、出現可能性，還是成立後優勢？各自映射哪個參數？ |
| 未知與反證 | 未觀察到什麼？哪個賽前可得反證會令判斷改變？保留／修改理由是什麼？ |

- **觀察機會不同不等於能力不同。** 無新公開系列、輪空或較少出賽，不能單獨推導「沒有修復」「反制較難成立」或休息加成。可以因版本／五人／對手已變而降低舊證據相關性，但須指明變化，對雙方用同一標準；不能把比賽數直接當情境出現頻率。未知保留為未知，仍可形成具名估計，不強迫均分權重或50%勝率。
- **功能完整與實際執行分開。** 選到前排、開戰和持續輸出，只證明陣容提供這些工具。若本對手已有阻斷方案，須說明控制如何接到傷害、輸出者是否能進場／存活；缺時間線就標推論，不能用終場KDA補出操作因果。失敗不一定來自BP缺功能，也可能是執行或合理變異。
- **跨系列變體不等於同系列深度。** 幾組中野更換、下路仍共享同一對英雄，可能只是同一核心的變體。列出核心重疊與已展示的替代；Fearless系列重置仍成立，但同一系列不能把互斥組合都算成可連用解法。沒有G4/G5證據不填虛構衰減，也不假裝深度已被證明。
- **有反向情境仍要查權重。** `scenario_space` 涵蓋雙方優勢，只證明可表達反向結果；不證明20%、30%或任何條件率合理。若正文說「不能由缺資料下結論」，權重卻只因缺資料向同一方傾斜，先消解矛盾並保存理由。沒有新證據不因賽果倒推應給多少。

## 發布與賽後裁決

發布前核對上述對照與 `weight_reason`、`probabilities_reason`、`counterargument` 是否一致。可直接修正引用／事實錯誤；需改數字時重建完整快照、保留舊版。研究未取得唯一權重並不阻止交付分析者估計，但必須誠實標示假設與敏感度。

復盤以事件去重，先列完整可評分集合，再挑機制案例：

- 區分「漏讀反證」「讀到但未映射」「已映射、發生率或強度待驗證」「資料無法判別／合理變異」。結果反轉不能單獨判定哪一類。
- 納入同觸發條件的命中案例；選到功能陣容仍輸，也不能推成「功能分析無效」。舊schema、不同賽區、BO3／BO5分層保留，不累加為獨立校準證據。
- 既有候選機制優先補證據，不每天新增同義因子。數值效應只進預先鎖定的隔離 challenger；以同截止、相同事件的配對前瞻樣本比較勝方、比分、Brier／log loss與覆蓋率。觀察數不足或退步則保留原版。
- 單場降信心、降注碼、反買熱門，或事後把20%改成50%，都不是此稽核的通過條件。
